Phase 1 · Week 1Practical intensive — five sessions

Meet Your Machine

This week is 100% hands-on. You will spend almost no time reading and almost all of your time clicking, typing, and dragging things on a real computer. Work through the five daily sessions in order — each one builds on the last.

Three rules for this week

1. Do it, don't read it. Only tick a box after you have physically performed the action on a computer.

2. Use two different computers. Wherever you see a Prove it box, repeat the task on a different PC — a lab machine, a friend's laptop, or a different account.

3. Don't skip ahead. Each day assumes you can already do everything from the day before.

What you need

  • Access to a desktop or laptop computer (Windows or macOS — instructions note the difference where it matters)
  • Access to a second, different computer at some point this week (a friend's, a lab PC, a library computer)
  • About 45–60 minutes per day
DAY 1 OF 5

Power & the Parts of a Computer

Basic

Before you touch software, you need total control over the hardware — turning it on and off the right way, every time.

Basic tasks

Physically point to and name: the screen/monitor, keyboard, mouse or trackpad, the power button, at least two ports (e.g. USB, charging port), and the power cable.

Press the power button once, then wait for it to fully load to the desktop or lock screen without touching anything else.

Windows: Start menu → Power icon → Shut down. Mac: Apple menu → Shut Down. Never hold the power button unless the computer is frozen.

Find "Restart" in the same power menu and use it, then wait for the computer to fully come back up.

Choose "Sleep" from the power menu, then wake it by pressing a key or clicking the mouse/trackpad.

Advanced task

Find and use the keyboard's dedicated brightness and volume keys (usually the F-row, marked with a sun and speaker icon), or the on-screen sliders if your keyboard has none.

Prove it — on a different computer

Sit at a computer you've never used before (different brand, or a laptop if you started on a desktop). Turn it on, and shut it down correctly using its menu. Notice what's different about where the buttons are.

DAY 2 OF 5

Mouse & Keyboard Mastery

Basic

Every single thing you'll ever do on a computer routes through these two devices. Today you drill the movements until they're automatic.

Basic tasks

On the desktop: left-click an empty area to select nothing, right-click to open a menu, then close it. Double-click a desktop icon to open it.

Press and hold the left mouse button on a desktop icon, move it to a new spot, then release.

Type at least 4 sentences about your day. Don't worry about mistakes — just get comfortable finding the keys.

Type a sentence with a capital letter using Shift, then type a full word in Caps Lock, then turn Caps Lock off and delete a mistake with Backspace.

Advanced tasks

Highlight text with Shift + arrow keys, copy with Ctrl+C (Cmd+C on Mac), then paste it elsewhere with Ctrl+V. Try Ctrl+X to cut instead.

Ctrl+Z undo, Ctrl+A select all, Ctrl+S save, Alt+Tab switch windows, and the Windows (or Cmd) key to open the start menu/launcher.

Prove it — on a different computer

On another PC, open its text editor and type, then copy a sentence and paste it three times using only keyboard shortcuts — no right-click menu allowed.

DAY 3 OF 5

Windows, Desktop & File Explorer

Basic

Today you learn to control what's on screen and where your files actually live.

Basic tasks

Open three different apps (e.g. Notepad, File Explorer/Finder, a browser), then practise the three buttons in the corner of each window.

Windows: drag a window's title bar to the left edge of the screen, then click a second window into the space on the right. Mac: hold the green button to choose a split-screen tile.

Click into each one and describe out loud what's inside.

Inside Documents, right-click an empty space → New → Folder, and name it exactly MyFirstFolder.

Inside MyFirstFolder, create a text file, rename it "notes-v1", move it to the Desktop, then delete it and check it appears in the Recycle Bin / Trash.

Open the Recycle Bin (Windows) or Trash (Mac), find "notes-v1", and restore it to its original location.

Advanced task

Create MyFirstFolder → Projects → 2026, then create a file and move it directly into the 2026 folder without opening it along the way.

Prove it — on a different computer

On a different PC (ideally the other operating system — try Mac if you used Windows, or vice versa), create the same MyFirstFolder → Projects → 2026 structure from memory.

DAY 4 OF 5

Advanced File Handling & Software

Advanced

Now you go beyond basic filing into the tasks that separate a confident user from a beginner.

Basic tasks

Windows: File Explorer → View → Show → File name extensions. Find one example each of .docx, .pdf, .jpg, .mp3 and .zip on the computer.

Use the search bar in File Explorer/Finder (or the Start menu / Spotlight) to find "notes-v1" without clicking through any folders.

Advanced tasks

Right-click MyFirstFolder → "Compress to ZIP" or "Send to → Compressed folder" (Mac: right-click → Compress). Then move the .zip file to a new folder and extract it there.

Using the Microsoft Store, Mac App Store, or a well-known official site, install one simple free app (e.g. a calculator app or PDF reader). Never install anything from a pop-up ad.

Windows: Settings → Apps → find it → Uninstall. Mac: drag it from Applications to the Trash.

Press Ctrl+Shift+Esc (Windows) or open Activity Monitor from Applications → Utilities (Mac). Find a running app you opened earlier and end/quit it from this window.

Windows: This PC → right-click your main drive → Properties. Mac: Apple menu → About This Mac → Storage.

Prove it — on a different computer

Copy your zipped MyFirstFolder onto a USB drive (or send it to yourself by email/cloud link), then open and extract it on a completely different computer to confirm it survived the trip intact.

DAY 5 OF 5

Settings, Connectivity & Troubleshooting

Advanced

Your final session of the week — the skills that make you the person people ask for help.

Basic tasks

Click the Wi-Fi icon in the taskbar/menu bar, join a network with its password, and confirm you're connected before opening a browser.

Windows: Windows+Shift+S to select an area. Mac: Cmd+Shift+4. Move the saved image into MyFirstFolder.

Check the operating system version, amount of RAM, and processor type via Settings → About (Windows) or Apple menu → About This Mac.

Advanced tasks

Right-click the drive in File Explorer/Finder and choose "Eject" before physically unplugging it — never pull it out directly.

Open an app, then use Task Manager / Activity Monitor (or Alt+F4 / Cmd+Option+Esc) to force it to close, simulating what you'd do if it froze.

Change the screen resolution or text size, and change the mouse pointer speed, in Settings — then set them back if you changed them on a shared computer.

Final challenge — the full transfer test

Sit at a computer you have never used before, ideally with someone watching. Without help, in under 15 minutes: connect to Wi-Fi, create a folder, take a screenshot and save it into that folder, check the system's storage space, and shut the computer down correctly. This is the real test of Week 1.

End of week self-assessment

Answer honestly. If you can't say yes to all six, revisit that day before moving to Week 2.

  • I can turn a computer on and shut it down correctly without guidance
  • I can copy, cut and paste using keyboard shortcuts
  • I can create, rename, move and delete files and folders confidently
  • I can zip and unzip a folder
  • I can install and uninstall a simple application safely
  • I performed the full transfer test on an unfamiliar computer
