Phase 1 · Week 2Practical intensive — five sessions

Your Operating System, Properly

Last week you learned to survive on a computer. This week you learn to run it — make it feel like yours, manage who can use it, add and remove software safely, connect real hardware, and keep it up to date. Still fully hands-on: work the five sessions in order.

Three rules for this week

1. Do it, don't read it. Only tick a box after you have physically performed the action on a computer.

2. Use two different computers. Every Prove it box asks you to repeat a task on a second machine, account, or operating system.

3. Never guess with someone else's computer. If it's a shared or borrowed machine, ask before creating accounts, installing software, or changing settings — and undo anything you changed just to practise.

What you need

  • The same computer you used in Week 1, with administrator access (ask whoever manages it if you're not sure you have this)
  • Access to a second, different computer for the transfer challenges
  • A printer to connect to, if one is available — a home, school or shared printer is fine (Day 4 has an alternative if none is available)
  • An internet connection for Day 3 and Day 5
DAY 1 OF 5

Personalise the Desktop

Basic

A computer that's set up the way you like it is faster to use and easier to navigate. Today you make it yours.

Basic tasks

Windows: Settings → Personalisation → Background. Mac: System Settings → Wallpaper. Pick a different image and confirm it applies.

Find the "Colours" or "Appearance" setting in the same personalisation menu and toggle it. Look at how a text editor's window changes with it.

Right-click an open app's icon and choose "Pin to taskbar" / "Keep in Dock". Then unpin a different app the same way.

Find "Lock screen" or "Screen Saver" settings and set it to lock after 5–10 minutes. This matters more once you set a password on Day 2.

Advanced task

Windows: change taskbar alignment (left/centre) or turn off a system tray icon in Settings → Personalisation → Taskbar. Mac: resize the Dock or turn on "automatically hide and show" in System Settings → Dock.

Prove it — on a different computer

On another PC, change its background and toggle light/dark mode without looking back at these instructions. Notice what's in a different place from your own machine.

DAY 2 OF 5

User Accounts & Sign-In Security

Basic

A shared computer needs separate accounts, and every account needs a real password. Today you take ownership of yours.

Basic tasks

Windows: Settings → Accounts → Your info. Mac: System Settings → Users & Groups.

Use Accounts → Sign-in options (Windows) or Users & Groups → Change Password (Mac). Choose a password that isn't a word found in a dictionary — combine unrelated words, numbers and a symbol.

Same Accounts settings page — set a photo or avatar for your profile.

Windows+L on Windows, or Ctrl+Cmd+Q on Mac. Then sign back in.

Advanced tasks

Windows: Settings → Accounts → Family & other users → Add account. Mac: Users & Groups → Add Account, type "Standard". Give it a name like "Guest Test".

Use the Start menu (Windows) or the menu bar's account switcher (Mac) — look for "Switch user" rather than "Sign out". Confirm the new account has its own separate desktop.

Back in your own administrator account, remove "Guest Test" from Accounts settings, confirming you understand this deletes its files too.

Prove it — on a different computer

On a shared or lab computer with more than one account already set up, sign out completely, then sign back in as yourself — don't just switch user this time.

DAY 3 OF 5

Installing & Uninstalling Software Safely

Advanced

Today's real skill isn't clicking "Install" — it's knowing when not to.

Basic tasks

Before installing anything, write down three warning signs (e.g. a pop-up demanding you "update now", a site not related to the software's real publisher, pressure to disable your antivirus). Say them out loud to whoever is checking your work.

Use the Microsoft Store or Mac App Store to install one small free tool you don't already have.

Advanced tasks

Pick a well-known, genuinely official site (e.g. a browser like Firefox, or a PDF reader). Download the installer, check it's the file you expected in Downloads, then run it and follow the setup steps yourself.

Windows: Settings → Apps → Installed apps → Uninstall. Mac: for most apps, drag from Applications to Trash — but check Settings → General → Storage first to see what's installed.

In the Apps/Storage list from the previous task, sort or look at app sizes to identify the largest app on the machine.

Prove it — on a different computer

On another PC, install the same official app-store tool from Basic Task 2 above, without needing to look up the steps again.

DAY 4 OF 5

Printers & Connected Devices

Advanced

Printers and peripherals are where most "the computer doesn't work" calls actually come from. Get comfortable connecting things.

Basic tasks

Settings → Bluetooth & devices → Printers & scanners (Windows) or System Settings → Printers & Scanners (Mac). Add the printer, then right-click it and set as default. No printer available? Add a "Microsoft Print to PDF" or "Save as PDF" virtual printer instead and treat it the same way.

From the printer's settings, choose "Print a test page", or open any document and print it, checking Preview first.

Plug it in, then check it appears in File Explorer/Finder (for a drive) or Settings → Devices (for a mouse/keyboard).

Advanced tasks

Print a document, then quickly open the printer's queue (double-click the printer icon in the system tray/menu bar) and cancel the job before it finishes.

Turn on a Bluetooth mouse, headphones, or speaker's pairing mode, then find and connect it from Settings → Bluetooth & devices. If none is available, describe the exact steps you would follow instead.

Eject the USB drive properly (as in Week 1), remove the printer if it was only for practice, and unpair the Bluetooth device.

Prove it — on a different computer

Connect the same USB drive or mouse to a different computer and confirm it's recognised there too, with no drivers to install.

DAY 5 OF 5

Updating & Maintaining the OS

Advanced

Your final session — keeping the operating system itself healthy and current.

Basic tasks

Windows: Settings → Windows Update → Check for updates. Mac: System Settings → General → Software Update.

If an update is offered, install it and allow the computer to restart if asked. If nothing is available, take a screenshot showing "You're up to date" as your evidence.

Settings → System → About (Windows) or Apple menu → About This Mac (Mac). Write it down.

Advanced tasks

Windows: Windows Update → Advanced options → Active hours, or "Pause updates for 1 week". Mac: toggle automatic update settings in Software Update → Advanced. Then set it back to normal.

Windows: right-click Start → Device Manager, expand a category, right-click a device → Update driver. Mac: drivers update automatically with macOS, so instead open System Information (Apple menu → About This Mac → More Info → System Report) and identify your Wi-Fi hardware.

Final challenge — the full transfer test

Sit at a different computer you haven't personalised yet. In under 20 minutes, without help: change its wallpaper, check its account type, install one app from an official store, connect any available peripheral, and check it for OS updates. This is the real test of Week 2.

End of week self-assessment

Answer honestly. If you can't say yes to all six, revisit that day before moving to Week 3.

  • I can personalise a desktop's background, theme, and taskbar/Dock
  • I can set a real password and create or delete a user account
  • I can tell a trustworthy download from a risky one
  • I can install and uninstall software through the proper settings
  • I can connect a printer or peripheral and manage a print job
  • I can check for and install operating system updates
