1. What is JavaScript?

JavaScript is a programming language used to make webpages interactive and able to respond to users.

HTML

Creates the structure and content.

CSS

Controls appearance and layout.

JavaScript

Controls behavior and interaction.

Examples of what JavaScript can do

  • Respond when a user clicks a button.
  • Read information entered into a form.
  • Calculate numbers.
  • Change text, images, colors and styles.
  • Show, hide and create webpage content.
  • Validate forms.
  • Build calculators, quizzes, games and other tools.

3. Create Your First Project

Create a folder named javascript-lesson-1. Inside it create these three files:

javascript-lesson-1/
├── index.html
├── style.css
└── script.js

Open index.html in your browser. The browser loads the HTML, then the linked CSS and JavaScript.

Important: The filenames must match exactly. If HTML says script.js, the JavaScript file must be called script.js.

4. Your First JavaScript

Start with the simplest JavaScript statement:

alert("Hello, JavaScript!");

alert() displays a browser message. Try it in the browser console or inside your JavaScript file.

Console practice

console.log("Hello from JavaScript!");
console.log(10 + 20);

console.log() sends information to the browser's Developer Console. It is very useful for testing and debugging.

5. Complete Example 1 — Change a Message

Goal: Click a button and make JavaScript change text on the webpage.

HTML — index.html

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h1>My First JavaScript Page</h1>
    <p id="message">Click the button below.</p>
    <button onclick="changeMessage()">Change Message</button>
  </div>

  <script src="script.js"></script>
</body>
</html>

CSS — style.css

body {
  font-family: Arial, sans-serif;
  background: #eef4ff;
  padding: 40px;
}

.card {
  max-width: 600px;
  margin: auto;
  background: white;
  padding: 30px;
  text-align: center;
  border-radius: 18px;
  box-shadow: 0 10px 25px rgba(0,0,0,.12);
}

button {
  padding: 12px 20px;
  border: 0;
  border-radius: 10px;
  background: #1457c5;
  color: white;
  cursor: pointer;
}

JavaScript — script.js

function changeMessage() {
  document.getElementById("message").innerHTML =
    "Excellent! JavaScript changed the webpage.";
}

How it works

  1. The button has onclick="changeMessage()".
  2. That calls the JavaScript function.
  3. getElementById("message") finds the paragraph.
  4. innerHTML changes its content.

6. Complete Example 2 — User Input and Greeting

This example teaches the important idea of input → processing → output.

HTML

<div class="card">
  <h2>Student Greeting</h2>
  <input id="name" type="text" placeholder="Enter your name">
  <button onclick="greetStudent()">Greet Me</button>
  <p id="greeting"></p>
</div>

CSS

.card {
  max-width: 500px;
  margin: 20px auto;
  padding: 25px;
  background: white;
  border-radius: 15px;
}

input {
  width: 100%;
  box-sizing: border-box;
  padding: 12px;
  margin-bottom: 10px;
}

button {
  padding: 12px 18px;
  cursor: pointer;
}

JavaScript

function greetStudent() {
  let name = document.getElementById("name").value;

  document.getElementById("greeting").innerHTML =
    "Hello, " + name + "! Welcome to JavaScript.";
}

New idea: .value reads what the user typed into an input.

7. Complete Example 3 — Two Inputs

JavaScript can read more than one input and combine the information.

HTML

<input id="student" type="text" placeholder="Student name">
<input id="school" type="text" placeholder="School name">
<button onclick="showInfo()">Show Information</button>
<div id="result"></div>

CSS

input {
  display: block;
  width: 100%;
  max-width: 500px;
  padding: 12px;
  margin: 8px 0;
  box-sizing: border-box;
}

#result {
  margin-top: 15px;
  padding: 15px;
  background: #f0f6ff;
}

JavaScript

function showInfo() {
  let student = document.getElementById("student").value;
  let school = document.getElementById("school").value;

  document.getElementById("result").innerHTML =
    "Student: " + student + "<br>School: " + school;
}

8. Complete Example 4 — Simple Calculator

This introduces JavaScript calculations. Later lessons will explain variables and operators in much greater detail.

HTML

<input id="num1" type="number" placeholder="First number">
<input id="num2" type="number" placeholder="Second number">
<button onclick="addNumbers()">Add</button>
<p id="answer"></p>

CSS

input {
  padding: 12px;
  margin: 5px;
}

button {
  padding: 12px 18px;
  cursor: pointer;
}

#answer {
  font-size: 20px;
  font-weight: bold;
}

JavaScript

function addNumbers() {
  let a = Number(document.getElementById("num1").value);
  let b = Number(document.getElementById("num2").value);

  let answer = a + b;

  document.getElementById("answer").innerHTML =
    "Answer: " + answer;
}

Important: Number() converts the input text into a number so JavaScript can perform numerical calculations.

9. Complete Example 5 — JavaScript Changes CSS

JavaScript can also change the appearance of an HTML element.

HTML

<div id="box">Change my appearance</div>
<button onclick="changeStyle()">Change Style</button>

CSS

#box {
  padding: 30px;
  background: #e8f0ff;
  border-radius: 15px;
  text-align: center;
  margin-bottom: 15px;
}

JavaScript

function changeStyle() {
  let box = document.getElementById("box");

  box.style.backgroundColor = "gold";
  box.style.color = "black";
  box.style.fontSize = "24px";
  box.style.fontWeight = "bold";
}
I can change my appearance.

10. Another Option: JavaScript Inside HTML

For small experiments, JavaScript can be written directly inside the HTML file:

<script>
  alert("Hello!");
</script>

However, for real projects, keeping JavaScript in a separate script.js file is usually easier to organize and maintain.

11. JavaScript Comments

Comments are notes for humans. The browser does not execute them.

// This is a single-line comment

/*
  This is a
  multi-line comment
*/

let name = "David"; // Store the student's name

Use comments to explain code that may not be obvious.

12. Basic JavaScript Rules You Should Know Now

1. JavaScript is case-sensitive.
name and Name are different.
2. Use quotation marks for text.
"Hello"
3. Use parentheses with functions.
alert("Hi")
4. Use braces for blocks.
function test() { }
5. Check spelling carefully.
document is not documentt.

16. Lesson Summary

  • HTML creates structure.
  • CSS controls appearance.
  • JavaScript controls behavior.
  • JavaScript can respond to events such as clicks.
  • JavaScript can read input using .value.
  • JavaScript can find HTML elements using document.getElementById().
  • innerHTML can change webpage content.
  • JavaScript can perform calculations.
  • JavaScript can change CSS through the DOM.
  • Keeping HTML, CSS and JavaScript in separate files helps organize projects.
