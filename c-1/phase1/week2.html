Your Operating System, Properly

This is a hands-on Windows 10 and Windows 11 lesson. You will change settings, inspect accounts, practise safe software management, connect a printer and check Windows Update.

🖥️ Practical🔊 Read Aloud 🪟 Windows 10 + 11✅ Exercises 🏆 Final Challenge

By the end of this lesson, you should be able to perform five everyday operating-system tasks safely and explain what you are doing.

1. 🎨 PersonaliseChange your desktop background and appearance.

1. 🎨 Personalise the Desktop

Personalisation controls how Windows looks. You can change the background, colours, themes and related appearance settings without changing your files.

Windows 10 — What to do

  1. Right-click an empty area of the desktop.
  2. Select Personalize.
  3. Select Background and choose Picture, Solid colour or Slideshow.
  4. Select Colors to choose an accent colour and other appearance options.
  5. Select Lock screen if you also want to change the lock-screen picture.
  6. Close Settings and confirm the desktop changed.

Windows 11 — What to do

  1. Right-click an empty area of the desktop.
  2. Select Personalize.
  3. Select Background and choose your preferred background.
  4. Use Colors to change accent and appearance settings.
  5. Use Themes when you want a coordinated set of visual settings.
  6. Close Settings and confirm the desktop changed.
YOUR PRACTICAL TASK: Change the desktop background to a picture you like. Then change an accent/colour setting. If the computer belongs to somebody else, restore the original setting after practising.

2. 👤 Manage User Accounts

A Windows account separates a person's files, settings and access. A Standard User is suitable for ordinary daily work. An Administrator can make wider system changes, so administrator access should be used carefully.

Standard UserSuitable for normal daily work. It has fewer system-changing privileges.
AdministratorCan make many system-wide changes, install software and change protected settings.

Windows 10 — What to do

  1. Open Start → Settings → Accounts.
  2. Select Family & other users.
  3. Under other users, select Add someone else to this PC if you have permission to create a practice account.
  4. Follow the prompts. If you need a local practice account, choose the local-account option when Windows offers it.
  5. Select the account and use Change account type to confirm whether it is Standard User or Administrator.

Windows 11 — What to do

  1. Open Start → Settings → Accounts.
  2. Select Other users.
  3. Select Add account if you have permission.
  4. Follow the prompts. Choose the local-account route if that is what you need for your practice.
  5. Check the account type and keep a normal practice account as a Standard User unless administrator access is actually required.
Safety: Never change another person's password, delete another person's account, or give yourself administrator access without permission.
YOUR PRACTICAL TASK: Open your account settings and identify whether your current account is a Standard User or Administrator. Do not change it. If you have permission to create a practice account, create a Standard User and remove it after the exercise if it is no longer needed.

3. 📦 Install & Uninstall Software Safely

Good computer users do not install every program they see. They check the source, publisher, purpose and system requirements before installing.

Safe installation checklist

1. Source
Use Microsoft Store or the software maker's official website.
2. Publisher
Check who made the program.
3. Requirements
Confirm the program supports your Windows version.
4. Installer
Read every screen and reject unwanted extras.

Windows 10

Install: Open Microsoft Store, search for the trusted app, check the publisher and select Get/Install. For traditional desktop software, use the developer's official download page.

Uninstall: Start → Settings → Apps → Apps & features → select the program → Uninstall.

Windows 11

Install: Open Microsoft Store, search for the app, check the publisher and select Get/Install. Or use the developer's official website.

Uninstall: Start → Settings → Apps → Installed apps → find the program → three dots → Uninstall.

Never use cracked software, key generators, random “PC cleaner” downloads or unknown pop-up installers. If Windows or your security software warns you about a file, stop and investigate the source instead of blindly bypassing the warning.
YOUR PRACTICAL TASK: Open your installed-app list. Find one program you recognise and identify its publisher. Do not uninstall system software or a program you need. If you have a disposable practice app and permission, uninstall it properly.

4. 🖨️ Connect a Printer

Printers may connect by USB or over a network. For a network printer, the computer and printer generally need to be reachable on the same network.

Windows 10 — What to do

  1. Turn on the printer.
  2. For USB, connect the printer cable. For Wi-Fi, connect the printer to the correct wireless network.
  3. Open Start → Settings → Devices → Printers & scanners.
  4. Select Add a printer or scanner.
  5. Wait for Windows to find it and select the printer.
  6. Complete any driver or setup instructions.
  7. Open the printer settings and print a test page when available.

Windows 11 — What to do

  1. Turn on the printer.
  2. Connect by USB or connect the printer to the correct Wi-Fi network.
  3. Open Start → Settings → Bluetooth & devices → Printers & scanners.
  4. Select Add device.
  5. Choose the detected printer and complete setup.
  6. Use printer settings to print a test page.
YOUR PRACTICAL TASK: If you have a printer, connect it and print a test page. If you do not have one, complete the simulator below and write the correct navigation path in your notebook.

5. 🔄 Update the Operating System

Windows Update provides operating-system updates, including security and feature updates. Always save your work before starting an update or restart.

Windows 10 — What to do

  1. Save your work.
  2. Open Start → Settings → Update & Security → Windows Update.
  3. Select Check for updates.
  4. Read the update status.
  5. If a restart is required, save everything and restart at a suitable time.

Windows 11 — What to do

  1. Save your work.
  2. Open Start → Settings → Windows Update.
  3. Select Check for updates.
  4. Read the update status.
  5. If a restart is required, save everything and restart at a suitable time.
Important: Do not deliberately power off the computer while Windows is installing an update. If you are on a laptop, connect the charger when appropriate.
YOUR PRACTICAL TASK: Open Windows Update and record the message you see: up to date, updates available, downloading/installing, or restart required. You do not have to install an update immediately on a shared/work computer without permission.

🏆 Final Practical Challenge

Imagine that you have been given a Windows 10 or Windows 11 computer that needs basic setup. Work through the scenario without guessing.

Scenario: The desktop is plain, you need to check the account type, a trusted practice application needs to be removed, a printer must be added, and Windows Update needs checking.
  1. Personalise the desktop and explain how to undo the change.
  2. Identify the current account type without changing another person's account.
  3. Find the installed-app list and describe how you would uninstall a trusted app safely.
  4. Open the printer settings and describe the correct Add Printer route for your Windows version.
  5. Open Windows Update and describe what you would do if a restart were required.
  6. Explain at least three safety rules you followed.
