Phase 1 · Week 2Practical intensive — five sessions

Your Operating System, Properly

Last week you learned to operate the machine. This week you learn to manage it: make it comfortable to use, keep accounts safe, install software without picking up viruses, connect a printer, and keep everything updated. Again, this is 100% hands-on.

Three rules for this week

1. Do it, don't read it. Only tick a box after you have physically done the action on a computer.

2. Ask before you change someone else's computer. On a lab, work or borrowed PC, get permission first. If a task needs Administrator rights you do not have, watch your teacher do it and explain the steps back.

3. Never use a password you use elsewhere for practice accounts, and never delete an account or app you did not create yourself.

What you need

  • A Windows or Mac computer where you may change settings (instructions note the difference where it matters)
  • An internet connection for Day 3 and Day 5
  • Access to a second computer for the "Prove it" boxes
  • A printer if one is available; if not, you will use Print to PDF
  • About 45–60 minutes per day
DAY 1 OF 5

Make the Desktop Yours

Basic

A computer you can read comfortably and find things on quickly is a computer you use well. Today you personalise the desktop, but you also learn where every setting lives, because you will need that on every machine you ever touch.

Basic tasks

Windows: press Win + I, then choose Personalisation. Mac: Apple menu → System Settings → Appearance.

Pick a picture, apply it, and look at the desktop to confirm it changed. Then change it back to something calm and professional.

Turn on Dark mode, look at how apps change, then choose whichever is easier on your eyes.

Windows: Settings → System → Display → Scale, or Accessibility → Text size. Mac: Settings → Displays. Increase the size one step and see the difference.

Right-click an open app on the taskbar (or Dock) and choose Pin. Confirm it stays after you close the app, then unpin it.

Advanced tasks

Find the screen-saver / lock-screen timeout and set it to 5 minutes. Then lock the computer manually with Win + L (Mac: Ctrl + Cmd + Q) and sign back in.

Open Settings → Time & language (Mac: General → Date & Time). Confirm the computer shows the correct local time for Nigeria (West Africa Time).

Prove it — on a different computer

On a computer that is not yours (with permission), find the wallpaper setting and the display size setting in under two minutes. Do not change anything permanently; just prove you can find them. Notice where the menus are different.

DAY 2 OF 5

User Accounts & Passwords

Basic

One computer, many people. User accounts keep everyone's files, settings and passwords separate, and they decide who is allowed to install software. Today you learn the difference between an Administrator and a Standard user, and how to protect an account properly.

Basic tasks

Windows: Settings → Accounts → Your info. Mac: System Settings → Users & Groups. Note the account name and whether it says Administrator.

Write two sentences in Notepad/TextEdit: what an Administrator can do that a Standard user cannot (for example install software and change system settings).

Windows: Settings → Accounts → Other users → Add account. Mac: Users & Groups → Add User. Name it Practice. Lab or borrowed PC? Ask permission first, or watch your teacher do it.

Use the Start menu (or Apple menu) to switch user. Notice that the desktop, wallpaper and files are completely different, then switch back to your own account.

Change the password of your Practice account (never a password you use elsewhere). A strong password has 12 or more characters, mixes words, numbers and symbols, and is not your name or phone number.

Advanced tasks

Sign out closes your apps. Lock keeps them running behind the lock screen. Switch user leaves your session running while someone else signs in. Try all three and say which one you would use before leaving a shared computer.

Only delete the account you created yourself. Choose to remove the account and its files, then confirm it no longer appears in the list.

Prove it — on a different computer

Look at the accounts on a second computer (do not change them). Which account is Administrator? Does it have a password? Write down what you would improve, without changing anything.

DAY 3 OF 5

Installing & Uninstalling Software Safely

Basic

Most computer problems, such as viruses, slow machines and pop-ups, begin with a careless install. Today you learn a safe routine: get software only from the official place, read every screen, and remove what you no longer need.

Basic tasks

Windows: Settings → Apps → Installed apps. Mac: Finder → Applications. Scroll through and name three apps you recognise and one you don't.

Search for a free program such as 7-Zip, VLC or Notepad++. Choose the result from the official website (check the address in the browser), not an ad or a 'free download' site.

On a download page, find at least one advert that looks like a Download button but is not the real one. The real link is usually a plain text link or the official file name (for example an .exe or .msi from the developer's own site).

Run the installer and read every screen. Untick any extra toolbars, browser changes or 'special offers', then finish the installation and open the app once.

Settings → Apps → Installed apps → ⋯ → Uninstall (Mac: drag the app from Applications to the Bin). Confirm it no longer appears in the list.

Advanced tasks

When Windows asks 'Do you want to allow this app to make changes?', look at the Verified publisher line. Say what you would do if it read 'Unknown publisher'.

Search for a free app, view its details and ratings, and install then remove it. Explain why the store is safer than random websites.

Prove it — on a different computer

On another computer, open the installed apps list and find the biggest app taking space and one you do not recognise. Do not remove anything; write down what you would check first.

DAY 4 OF 5

Printers, Devices & Bluetooth

Basic

A printer that will not print is one of the most common office problems. Today you learn how a computer finds and talks to devices, and how to print exactly what you want, with no wasted paper.

Basic tasks

Windows: Settings → Bluetooth & devices → Printers & scanners. Mac: System Settings → Printers & Scanners. Note which printers are already listed.

Click Add device and let the computer search. If a real printer is nearby, add it (USB cable or the same Wi-Fi network). If not, stop at the list of found devices and explain what each entry means.

Open your Week 1 practice note. Press Ctrl + P, choose Microsoft Print to PDF (Mac: PDF → Save as PDF) and save it to your Documents folder. Open the PDF to check it.

In the print window, set: number of copies, only the pages you need, portrait or landscape, and black and white. Look at the preview before printing.

Open the Bluetooth setting, switch it on, look at the list of nearby devices without pairing with anything you don't own, then switch it off again.

Advanced tasks

Open the printer's print queue (double-click the printer). Cancel a waiting job and explain what a stuck queue looks like.

Find the option to set a printer as default and say when you would use it. Then check whether the computer is set to 'Let Windows manage my default printer'.

Prove it — on a different computer

On a different computer, open Printers & scanners and print a test page or a PDF. If it fails, write down the exact message on screen and the first two things you would try.

DAY 5 OF 5

Updates, Storage & Keeping It Healthy

Basic + Project

A computer that is never updated becomes slow and unsafe. Today you check for updates, see where your storage goes, and finish with a practical project: setting up a computer for a new user from start to finish.

Basic tasks

Windows: Settings → Windows Update → Check for updates. Mac: System Settings → General → Software Update. Note whether updates are waiting.

Windows Update → Advanced options (or Schedule restart). Set active hours that match the time you normally work so it does not restart mid-lesson.

Windows: Settings → System → About. Mac: Apple menu → About This Mac. Write down: device name, processor, memory (RAM), and Windows / macOS version.

Settings → System → Storage (Mac: General → Storage). Name the top three categories using space and how much free space is left.

Empty the Recycle Bin / Bin and clean temporary files using the Storage or Cleanup suggestions. Never delete anything you do not recognise in system folders.

Advanced tasks

Find the power mode (Best performance / Balanced / Best power efficiency) and battery usage. Explain which setting you would use on a laptop that must last all day.

On a computer where you have permission, do all of these in order: set a clear wallpaper, create a Standard account with a password, install one useful free app from its official site, add or test a printer (or print to PDF), and check for updates. Write a short checklist of what you did.

Prove it — on a different computer

Repeat your final project checklist on a second computer, or sit with a partner who follows your checklist step by step. Every step you had to explain aloud is a step that needs to be clearer.

End of week self-assessment

Answer honestly. If you can't say yes to all six, revisit that day before requesting Week 3.

  • I can change the wallpaper, theme, text size and screen lock settings
  • I can tell an Administrator from a Standard account and create one safely
  • I can install and remove an app using only the official source
  • I can add a printer or print to PDF and choose the right print options
  • I can check for updates and see how much storage is left
  • I completed the final project on a second computer
