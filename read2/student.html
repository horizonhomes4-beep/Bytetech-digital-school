Privacy and limitations

This teaching demo requests Gmail readonly permission. It retrieves one latest message only after a student action. Sharing is a separate explicit action. It does not read WhatsApp, TikTok, Facebook or other apps; it does not bypass encryption; and it does not run a hidden background collector. Attachments are not included. Message body display is limited to 20,000 characters.
